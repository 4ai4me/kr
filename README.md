# 한국어 일과사전 — 한국어의 만능키, 거시기 편

> **"거시기가 거시기를 거시기혀서 거시기하냐?"**  
> 한국어 대표 맥락어 **거시기**의 50가지 세부 용법을 수록한 언어 아카이브입니다.

🔗 **[라이브 사이트 보기](https://4ai4me.github.io/kr/)**

---

## 📖 소개

| 항목 | 내용 |
|---|---|
| **수록 용법** | 총 50개 세부 용법 |
| **분류 체계** | 8대 품사 치환 + 인지·사회·화용론적 분류 |
| **카드 수** | 11장 (9:16 모바일 세로 규격) |
| **기능** | 좌우 슬라이더 탐색 + 고해상도 PNG 일괄 다운로드 |

## 🛠 기술 스택

- **단일 HTML 파일** — 빌드 도구 없이 브라우저 직접 실행
- **Noto Serif KR / Noto Sans KR** (Google Fonts)
- **html2canvas v1.4.1** — DOM → PNG 캡처
